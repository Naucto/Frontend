The icons that stand alone: the top bar, the rail, an empty state, an icon-only button tall
enough to hold one. Each is drawn for a box of eight cells by eight, three pixels a cell, so
`nc-icon` draws it at 24px and never scales it.

The format is that of icons-18.txt, which draws every name here for the box beside words.
