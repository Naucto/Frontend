# Naucto Frontend

---

## Prerequis

- [Node.js](https://nodejs.org/) should be installed

---

## setup

```bash
npm install
```
  
#### vscode workspace recommended for eslint
click to **File** then **Open workspace from file** and select the **settings/vscode/frontend.code-workspace** file

## Development

```bash
npm run dev
```

## Testing

```bash
npx jest            # unit tests
npm run cypress:run # e2e tests
```

## Docker

Start the Backend stack first — it creates the shared `naucto` network this
compose file joins as external.

```bash
docker compose up --build
```

The backend URL is inlined into the bundle at build time from `VITE_BACKEND_URL`
(default `http://localhost:3000`), so changing it requires a rebuild, not just a
restart.

---

It will then run on http://localhost:3001
